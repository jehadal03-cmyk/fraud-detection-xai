# نظام كشف الاحتيال المالي مع الذكاء الاصطناعي القابل للتفسير (XAI)

مشروع فردي لمادة Selective Topics

## الوصف المختصر
نظام يصنّف المعاملات المالية إلى (احتيالية / سليمة) باستخدام موديل XGBoost، مع تفسير كل قرار لحظيًا باستخدام SHAP عبر واجهة Streamlit تفاعلية.

## Problem Statement
الاحتيال المالي (Credit Card Fraud) يسبب خسائر كبيرة للبنوك والمستخدمين سنويًا. النماذج التقليدية لكشف الاحتيال (مثل الشبكات العصبية المعقدة) تعمل غالبًا كـ "صندوق أسود" (Black Box)، بحيث لا يمكن معرفة سبب تصنيف معاملة معينة كاحتيال، مما يصعّب على المحللين الماليين الوثوق بالقرار أو تبريره للعميل أو الجهات الرقابية.

## Objectives
- بناء نموذج تعلم آلي دقيق لتصنيف المعاملات المالية
- تطبيق تقنيات الذكاء الاصطناعي القابل للتفسير (XAI) لتوضيح أسباب كل قرار
- توفير واجهة تفاعلية تعمل بشكل لحظي (Real-Time) لعرض القرار والتفسير معًا
- التعامل مع تحدي البيانات غير المتوازنة (Imbalanced Data) الشائع بمجال كشف الاحتيال

## Methodology
1. تحميل بيانات معاملات بطاقات ائتمان حقيقية (284,807 معاملة، 492 منها احتيالية فقط)
2. معالجة البيانات: توحيد مقياس عمود Amount، حذف عمود Time غير المفيد
3. تقسيم البيانات إلى تدريب واختبار (80/20) مع الحفاظ على نسبة الاحتيال بكلا الجزئين (Stratified Split)
4. تدريب موديل XGBoost مع معامل scale_pos_weight للتعامل مع عدم توازن البيانات
5. تقييم الأداء باستخدام Precision, Recall, F1-score, Confusion Matrix
6. تطبيق SHAP (TreeExplainer) لحساب وتفسير تأثير كل خاصية على قرار الموديل
7. بناء واجهة Streamlit تعرض القرار والتفسير بشكل لحظي

## System Architecture

→ Streamlit App (app.py)
├── يحمّل الموديل المحفوظ

└── SHAP (explain.py) يفسّر القرار لحظيًا

## How the AI Works
يعتمد النظام على موديل XGBoost (خوارزمية Gradient Boosted Trees)، وهو مجموعة من أشجار القرار المتتالية، كل شجرة تصحح أخطاء الشجرة التي قبلها. النموذج يتدرب على أخذ قرار بناءً على 29 خاصية رقمية لكل معاملة (نتيجة معالجة PCA مسبقة على البيانات الأصلية لأسباب خصوصية، بالإضافة لعمود المبلغ المالي).

## How XAI Was Applied
تم استخدام مكتبة SHAP (SHapley Additive exPlanations)، وتحديدًا TreeExplainer المخصص لموديلات الأشجار. هذا يسمح بحساب "قيمة SHAP" لكل خاصية في كل معاملة على حدة، توضح مدى ومقدار مساهمة تلك الخاصية في دفع القرار النهائي نحو "احتيال" أو "سليمة". يتم عرض هذا بصريًا عبر رسم Waterfall Chart يظهر فور طلب المستخدم لتفسير أي معاملة، مما يحقق شرط الـ Real-Time المطلوب.

## Results
- دقة الموديل الإجمالية (Accuracy): ~100%
- على فئة الاحتيال تحديدًا: Precision = 0.81, Recall = 0.84, F1-score = 0.82
- الموديل نجح في كشف 82 من أصل 98 حالة احتيال حقيقية بمجموعة الاختبار

## Limitations
- البيانات غير متوازنة بشدة (0.17% فقط احتيال)، مما يجعل تقييم الأداء يتطلب مقاييس متخصصة بدل الاعتماد على Accuracy وحده
- الخصائص (V1-V28) معالجة مسبقًا بـ PCA، مما يصعّب تفسيرها بمعناها الحقيقي (مثل "نوع المتجر" أو "الموقع الجغرافي")
- النموذج مدرّب على بيانات تاريخية، وقد يحتاج إعادة تدريب دوري لمواكبة أنماط احتيال جديدة

## Future Work
- تجربة نماذج أخرى (مثل Random Forest, LightGBM) والمقارنة بينها
- ربط النظام ببيانات حية (Streaming Data) بدل بيانات ثابتة
- إضافة SHAP Summary Plot لعرض أهم الخصائص المؤثرة على مستوى النموذج ككل، وليس فقط لمعاملة واحدة

## Conclusion
يوضح هذا المشروع تطبيقًا عمليًا وحقيقيًا لمفاهيم الذكاء الاصطناعي القابل للتفسير (XAI) في مجال حساس وواقعي وهو كشف الاحتيال المالي. النظام لا يكتفي بإعطاء قرار، بل يفسره بشكل لحظي ومقنع، مما يزيد من إمكانية الوثوق بالنموذج واستخدامه فعليًا في بيئة عمل حقيقية.
