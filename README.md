# نظام كشف الاحتيال المالي مع الذكاء الاصطناعي القابل للتفسير (XAI)

مشروع فردي لمادة Selective Topics  

## الفكرة
نظام يصنّف المعاملات المالية (احتيالية / سليمة) باستخدام XGBoost، مع تفسير كل قرار لحظيًا باستخدام SHAP عبر واجهة Streamlit تفاعلية.

## الجانب اللحظي (Real-Time)
النظام يعمل بشكل لحظي: عند اختيار أو إدخال معاملة، يقوم النموذج بحساب التنبؤ وتوليد تفسير SHAP فور الطلب، دون أي معالجة مسبقة أو نتائج مخزّنة مسبقًا.

## البيانات
Dataset: Credit Card Fraud Detection (Kaggle)
ضع ملف creditcard.csv داخل مجلد data/ قبل التشغيل.

## المتطلبات
pip install -r requirements.txt

## التشغيل
streamlit run app/app.py

## هيكل المشروع
- src/ — معالجة البيانات وتدريب الموديل
- app/ — واجهة Streamlit
- models/ — الموديل المدرّب
- notebooks/ — تجارب واستكشاف
